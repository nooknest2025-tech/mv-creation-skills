# mv-intake-analysis

**モデルの目安: 軽い/速いモデル＋推論 low〜medium で十分**（決まった手順をコマンドで回す工程。`codex --profile mv-run`）

## 制作全体との接続

新規MV制作では [mv-workflow](../mv-workflow/SKILL.md) を入口にする。ファイル確認・曲尺や拍の解析は演出提案の材料として先に進めてよい。自動プレビューは解析・配置の初稿であり、演出の合意や完成確認の代わりにしない。作り方が未選択なら、本番用プリセットを勝手に確定しない。

## やること
1. `input/` を見る。曲が無ければ止めて「input に mp3/wav を入れてください」と伝える。
2. `cd remotion && npm run mv -- --stills-only` を実行。最初に日本語の要約（何を使い、何を自動で補うか）が出る。
   - 歌詞JSON / SRT / LRC / VTT / ASS → そのまま使う
   - 歌詞 .txt だけ → faster-whisper で音声に位置合わせ（無料・ローカル）
   - 歌詞なし → faster-whisper で書き起こし（ボーカル無しの曲は 0 行で正常）
   - 画像/動画なし → 曲に反応する抽象映像
   - `input/stems/vocals.wav` があれば原曲と別に照合し、推定を比較する
3. 解析結果（BPM・セクション）が変なら直す: `npm run edit -- "BPMは128"`、拍がずれていたら `"拍を半拍ずらして"`。見て直すなら `npm run timing`。
4. 手で直した値は `timing.locked` に入り、再解析しても消えない。

## 解析を過信しない

歌詞に時刻がある場合も含め、`npm run mv` はローカルで歌声と歌詞の照合を試み、冒頭・中盤・終盤の音の立ち上がりと拍グリッドを比較して `out/sync-audit.json` に確認候補を記録する。モデルや依存が使えないときは未実施の理由を残して続行する。自動認識や立ち上がりの差は正解の証明ではない。既存時刻は上書きしない。

パックの `scripts/common.ts` は一定テンポを仮定したBPM・拍位置の推定。別途 `out/beat-track.json` の音の立ち上がりを使った可変拍候補を既定で試すが、歌声・弱いリズム等で誤ることがある。セクションは8小節単位の音量比からの仮ラベル。サビや曲構造を理解した結果ではない。BPMの半分/倍、拍位置、曲の冒頭・中盤・終盤のずれ、テンポ変化の有無を音付きで検討し、難しければ未確認とする。音量だけで感情・ジャンル・サビを確定しない。

歌詞の自動位置合わせは発声の入り・語尾・間奏・繰り返しを複数区間で確認し、供給歌詞と脱落・重複を照合。楽曲全体が正確とは未検証で断定しない。曲・解析方法・推定/手修正/聴取の状態、残るずれを `production-review.md` に記録。手動ロックを優先し、別解析で勝手に上書きしない。

## 歌唱時刻と表示時刻

`out/lyric-timeline.json` は原曲の歌唱時刻の仮推定と表示時刻を別々に記録する。分離済み歌声があればそれも個別に解析し、時刻差や素材の長さ、開始位置未検証を記録する。歌声素材の長さが同じでも同期済みとは限らない。素材がないときはローカル導入済み・モデル取得済みの Demucs でオフライン分離を試す。使えなければ理由を記録して原曲で続行し、分離成功と偽らない。文字単位の推定は補間を含みうる。すべて聴取未確認として扱い、手動編集を上書きしない。拍解析と最終音声は原曲を使う。

## 注意
- 失敗時は、依存不足・音声デコード・モデル取得を直前のエラーで区別する。まずパック内の `.python-deps/`（venv または pip --target）と `MVPACK_PYTHON` を確認する。導入済みなら再インストールせず同じPythonで読み込めるようにする。未導入と確認できた場合のみ、無料の依存追加を説明して承認後にインストールする。
- 同梱ffmpegは機能が限られるため、音声読み込みは共通スクリプトのPCM s16le WAV経路を使う。`f32le`出力やPyAV経由への場当たり的な切替を既定にしない。`doctor`の依存検出合格だけで解析成功と断定せず、実際の音源の読み込み・同期処理が通った範囲を報告する。
- 提供済み歌詞を省いたり均等配置したりする代替案は、同期成功として扱わない。失敗した工程と未確認事項を制作記録に残す。
- 自動書き起こしは誤字が出る。歌詞テキストが提供済みか確認し、提供されていなければ有無を聞く。提供済みの歌詞を再要求しない。自動同期の後は `mv-timing-edit` で音付きの確認へ進む。

## この環境でのパックの場所

作業ディレクトリまたは上位ディレクトリから、`AGENTS.md` と `remotion/package.json` を持つ制作パックのルートを確認する。管理用ワークスペースに `skill-pack-v3/MV_SKILL_PACK/` がある場合はそこを使う。PC固有の絶対パスを前提にしない。コマンドはパック内の `remotion/` で実行する。
