# mv-timing-edit

**モデルの目安: 軽い/速いモデル＋推論 low〜medium で十分**（決まった手順をコマンドで回す工程。`codex --profile mv-run`）

## 自動同期後の確認

新規制作では [mv-workflow](../mv-workflow/SKILL.md) に沿い、自動同期の結果を音付きで再生する。歌詞の入り・フレーズ境界・語尾、サビ頭、最後の歌詞と最後の1秒を確認し、ずれた行を調整する。変更した値はロックし、短い区間を再生して再確認する。

プロジェクトの `production-review.md` に確認した区間、問題、調整値、再確認結果を記録する。再生・聴取できない場合は未確認とし、音付きの確認用動画と修正方法を提示する。静止画・波形・自動QAだけで「同期確認済み」としない。既に確認済みの区間は変更がなければやり直さない。

## 口同期・カットの局所修正

「ここが遅い」が、口の動き、字幕、カットのどれを指すか特定する。使用中の版と元曲位置を記録する。一定の遅延なら素材の開始位置、途中からずれる場合は区間ごとの動きを調べる。元音声の速度・ピッチは維持する。

元動画を残し、使用範囲や映像側の速度を編集データで調整する。ユーザーが映像の速度調整を求めた場合は、局所的な緩やかな速度変化を候補にし、対象区間・倍率・時間対応を記録する。無関係な区間へずれを移さない。途中のフレーム除去や末尾静止を自然な同期修正として隠さず、カクつき・補間の口元の歪みも確認する。生成時の音声区間合わせのルールと、ユーザー指示による生成後の映像編集を区別する。

Studioを使う場合は [編集と保存の手順](../mv-workflow/references/review-and-studio.md) を読み、手動キーを保持する。素材を延ばす場合は生成元の余白と隣接カットの重複を確認する。

## ブラウザのエディタ
`npm run timing` → http://127.0.0.1:5177/ 。波形・拍・セクション・歌詞・カットが並ぶ。ドラッグ/数値で修正 → 保存で `mv.config.json` の `timing` に入り、触った項目は `locked`（再解析しても残る）。
Studio（`npm run studio`）も同じ設定を読むので、保存後に再生して確認できる。

## 静止画の全体図
`npm run timeline` → `projects/<曲名>/out/timeline.png`。

## 言葉で
`"歌詞を0.2秒早く"`、`"サビの歌詞の消えるのを0.3秒遅く"`、`"3行目は12.5秒から"`（perLine）、`"画は0.1秒前から切り替え"`。

## この環境でのパックの場所

作業ディレクトリまたは上位ディレクトリから、`AGENTS.md` と `remotion/package.json` を持つ制作パックのルートを確認する。管理用ワークスペースに `skill-pack-v3/MV_SKILL_PACK/` がある場合はそこを使う。PC固有の絶対パスを前提にしない。コマンドはパック内の `remotion/` で実行する。
