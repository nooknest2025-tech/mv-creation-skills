# プロの演出ルール（プランナーが実際に使う知識ベース）

このパックの自動演出は「派手さ」ではなく**曲と画に合っていること**を最優先にします。下のルールはすべてコード（`remotion/src/lib/direction.ts` / `critic.ts` / `hybrids.ts` / `visual.ts`）で実装され、テスト（`tests/pro.test.ts`）で確かめています。
参考にしたのは**技法**だけで、作品・文章・コードはコピーしていません（出典は末尾）。

## 1. 構成と物語
| ルール | 実装 |
|---|---|
| 盛り上がりの山（Aメロ < Bメロ < サビ、ラスサビが頂点） | `targetIntensity()` がセクション＋音の強さから「勢い」を計算し、文字の動きの強さをそれに合わせる。critic がサビ ≤ Aメロ、ラスサビ < 1サビ を指摘 |
| サビの前は「ため」（抑えてから解放） | Bメロの強さは中間に固定、プリセットの「サビ前1拍の黒」(preChorusBreak) |
| モチーフ／コールバック（繰り返しのサビは同じ動きで、強さだけ上げる） | 同じ種類のセクションは前回の動きを踏襲（変化多めの時だけ作り直し） |
| フック（冒頭10秒で掴む） | coldOpen（最強の画で始める）＋サビ頭の見せ場1回。critic が「サビに見せ場なし」を指摘 |
| 締め（余韻） | 最後のカットは2拍以上。critic が短すぎを指摘 |
| サビの回数分だけ盛り上げ、落ちサビで何をするか決める（加藤マニ氏） | ラスサビ判定（isLastChorus）で強さ +12% |

## 2. カメラと編集
| ルール | 実装 |
|---|---|
| 毎拍は切らない。オフビートで次のオンビートを効かせる、感情の所は「ためる」 | プリセットごとの拍単位カット＋低エネルギーで長く。critic が「同じ長さのカット10連続」を指摘 |
| 同じ動きを続けない | critic が「同じカメラの動き3連続」を自動修正（ユーザー指定のカットは提案のみ） |
| 動きには理由を（モチベーテッド・ムーブ） | 役割（ハイブリッド）ごとに動きを決める: 歌唱=顔へ寄る、ストーリー=引き・パララックス、ダンス=ホイップ・ズームパンチ、ライブ=手持ち・クレーン、回想=ゆっくり引き |
| 同じ画は2秒以上だらだら続けない（8秒で4枚くらい） | critic が「動きのない静止画4秒超」を指摘 |
| カット点は拍か歌い出しに | critic が拍・歌い出しから 0.09 秒以上ずれたカットを指摘 |
| マッチカット | matchCut レシピ（同じ寄りの連鎖） |

## 3. 構図・色
| ルール | 実装 |
|---|---|
| 歌詞は顔・視線の先・ごちゃごちゃした所を避け、余白（ネガティブスペース）へ | `scripts/visfeat.py` で上/中/下の帯のごちゃつき（エッジ密度）と顔の位置を測り、`placeText()` がコスト最小の帯へ |
| 背景に対して読める色（WCAG 4.5:1 以上） | `readableFill()` が帯の輝度とのコントラスト比を計算し、足りなければ白/黒＋反対色フチに切替（理由を記録） |
| 色の設計（セクションごと） | ジャンルの配色（本文/サビで切替）＋プリセットのグレード、回想は彩度を落とす |

## 4. 歌詞モーションの原則
| ルール | 実装 |
|---|---|
| 大技は1セクション1回（抑制） | プランナーが見せ場を1回だけ置き、critic が重複を降格 |
| 読める時間（最短 5/6 秒、日本語 7字/秒 + 0.3秒） | `minOnScreen()`。足りない行は延長、延長できなければ「行を分ける」提案 |
| 早口は語単位・読みやすい動きに | 10字/秒超の行は可読性の高い動きに差し替え |
| 強調（キーワードは太く大きく・色） | 語エフェクト（glow/red/shake…）と書体の語指定 |
| 予備動作・オーバーシュートのイージング | 合成モーション（`styles/motion.tsx`）の ease: back / elastic / expo / soft |
| 発音（モーラ）に合わせて出す | 文字ごとの発声時刻（chars[].t0）で出現・強調 |

## 5. ハイブリッド構成（12種）
`ストーリー＋リップシンク` / `サビだけ歌うシーン` / `ストーリー＋ダンス` / `リップシンク＋リリックPV` / `ライブ＋回想` / `一発撮り＋情景カット` / `ダンス＋タイポグラフィ` / `演奏×ドラマのインターカット` / `ワンカット＋インサート` / `リリックPV＋ストーリー` / `コンセプト映像＋歌唱` / `リップシンク＋サビダンス`。
セクションごとに役割の割合（例: サビ 70% 歌唱）を持ち、交互に混ぜて配置。歌唱カットには顔のある画像、文字主役カットには顔のない画像を回し、生成プロンプトにも役割が入ります。顔のある画像が無ければ歌唱が必要な構成は自動では選びません。

## 6. 手動モードとの関係
ユーザーが指定した所はそのまま。critic は「提案」だけを出します（`director_note.md`）。

# プロのモーション・モーショングラフィックス・半自動・パーツアニメ（pro-motion）

「自動で作った文字PVが安っぽい」原因は、だいたい次の4つでした: ①直線的なフェード ②画面中央に同じ大きさで置くだけ ③色が多すぎる／既定色のまま ④拍と関係なく動く。
プロの文字PV・モーショングラフィックス10本を見て、**作品そのものではなく「共通するルール」だけ**を取り出し、エンジンに組み込みました（素材・デザインの複製はしていません）。

## 1. 動きの共通ルール（`remotion/src/lib/pro.ts`）
| ルール | 中身 |
|---|---|
| イージング | expo-out `cubic-bezier(0.1,1,0,1)`（最初の15%で約9割動き、あとはゆっくり漂う）／snappy `(0.1,0.9,0.2,1)`（ポーズtoポーズ）／バネ（行き過ぎ約1.1〜1.2）。直線フェードは使わない |
| ポーズtoポーズ | パッと決めポーズへ→止まっている間もわずかに拡大・移動し続ける（完全停止しない） |
| ずらし | 1文字（音節）ごとに2〜3フレーム、行ごとに5〜8フレーム。歌詞に文字単位のタイミングがあれば実際の発声時刻に合わせる |
| 出入り | フェードではなく「マスクから滑り出る」「マスクへ加速して消える」 |
| 叩きつけ | 300〜500%→100%を2〜6フレーム。**動いている間だけ**ブレをかける |
| ほか | 横ストレッチ（300%→100%）、線が伸びてから文字を引き出す、ベタ箱が縮んで文字が現れる、斜めマスク、ラベル帯が先に伸びて文字が乗る |
| 文字の強弱 | 要の語は大きく、助詞（は が を に の へ と も）は50〜70%で明朝に。太いゴシックは字間を詰める。小さく字間を広げた英数字を飾りに。縦の柱、画面からはみ出す巨大文字（形として） |
| レイアウト | 3×3グリッドの交点に置き、行ごとに対角線上へ視線を流す。速い区間は−10〜+15度の小さな傾き |
| 色 | セクションごとに3〜4色だけ（背景・文字・差し色・補助）。歌詞に「赤」「青」→差し色が変わる、「モノクロ」→白黒に |
| 拍アクセント | 小節頭で2フレームだけ画面反転、拍で小さく拡大・回転、伸ばした叫びで揺れ（**拍グリッドからの近似。ドラム音の検出ではありません**） |

新しい文字スタイル（既存のスタイル名はそのまま）: `pro_slide` `pro_smash` `pro_stretch` `pro_line` `pro_box` `pro_diag` `pro_label` `pro_pop` `pro_tanzaku` `pro_pillar` `pro_crop`。既存の `reveal`（expo-out）と `bounce`（バネ）も共通ルールに置き換えました。

## 2. モーショングラフィックス（`src/lib/mograph.ts`, `src/render/MoGraph.tsx`）
- 図形: 円・四角・線・三角（ポーズtoポーズで拍ごとに移動）、同心円バースト、拍で飛ぶ粒、斜め線のスイープ
- 場面転換（約10フレームで覆って約9フレームで開く。色は次のセクションの色）: 円／四角／波紋／雲のようなワイプ／文字の中へズーム／巨大文字が押し出す／斜め線スイープ／ゆっくり直線ワイプ
- 奥行き: 奥に大きく薄い英字、手前に照準・枠・小さな等幅の数字（UI風）
- 質感: 粒子ノイズ、網点、RGBずれ・アナグリフ（アクセントの瞬間だけ）
- 遅いモード: 短冊の枠に縦書き明朝、直線ワイプ、長い間
- 画像・動画と一緒に使えます（画の上では控えめ、全画面タイポ／モーショングラフィックスの区間では背景ごと描きます）。

## 3. 自動ディレクター（曲調×セクション）
| 曲調 | Aメロなど | サビ | 色 | 転換 |
|---|---|---|---|---|
| ロック | 白黒・UI、スライド/箱 | 8分〜16分のカット（素材が少ない時は1拍）、叩きつけ・巨大切れ文字、毎拍のアクセント | 白黒＋赤 | 四角・文字ズーム・斜め・押し出し |
| バラード | 短冊・縦書き明朝・長い間 | スライド・縦の柱、幾何学は控えめ | 夕暮れ・藍 | ゆっくりワイプ・雲・波紋 |
| エレクトロ | 照準UI・ラベル | ストレッチ・斜め・バースト | ネオン・蛍光 | 円・文字ズーム・押し出し |
| ポップ | 色ブロック・バネ | バネ・ストレッチ・バースト | ポップ・キャンディ | 円・四角・波紋 |
| シティポップ／和 | 色ブロック／短冊 | ライン・ポップ／巨大切れ文字 | シティ／紙白＋朱 | 四角・円／ワイプ |

各セクションの理由は書き出し時のログと `props.mographNotes` に日本語で出ます。昔の見た目に戻すなら「プロ演出オフ」、図形だけ消すなら「モーショングラフィックスなし」。

## 4. 見せ方の組み合わせ（複数選択）
物語／リップシンク／ダンス／ライブ／**リリックモーション**（画の上に動く歌詞）／**タイポグラフィ**（文字が主役の全画面）／**モーショングラフィックス**（図形が主役）を自由に組み合わせられます。
- 例: 「ダンス＋リリックモーションで」→ 全編ダンスの画に動く歌詞を重ねる
- 「物語＋タイポグラフィで」→ Aメロは物語75%＋要所で全画面の文字、サビは全画面タイポ60%＋物語
- 「リップシンク＋モーショングラフィックスで」→ サビは歌唱50%＋図形のバースト、場面転換は図形ワイプ
- 何も選ばなければ、曲調と素材（顔がある画像か等）から自動で提案します（ログに「自動提案」と理由）。

## 5. 半自動モード（start の 2 番）
質問は6つだけ。どれも★おすすめがあり、Enter でそのまま進めます。
1. 見せ方（複数OK） 2. 画像テイスト（アニメ／実写風／イラスト／図形中心／手持ち画像） 3. シーンの細かさ（ゆったり／標準／テンポよく。約何カットかを表示） 4. 動画化（静止画のみ／サビなど一部／全部。費用の目安を表示。実際の生成は `npm run gen -- plan` で見積もり→承認後） 5. リリックの雰囲気と書体 6. キャラの動き（パーツアニメ）
最後に計画を一覧で見せ、「この計画でよいですか？」で確認してから作ります。Codex でも「半自動で作って」と言えば同じ質問を会話で行います。

## 6. パーツアニメ（Live2D風の切り絵）
`npm run parts -- import キャラ.psd`（または PNG フォルダ）→ 頭・体・腕・髪・目・口などの種類、回転の支点、親子、前後を自動推定 → `check_sheet.png` で確認 → `npm run mv` で自動的に使われます。
- 1枚絵からの自動分解 `npm run parts -- split 画像.png` は無料・ローカルですが**粗い**です（頭／体／左右の腕だけ。隠れた所は推測で塗り足し）。必ず確認シートを見て、必要なら `npm run parts -- set 名前 頭.pivot=x,y` で直してください。
- 動き: 待機・うなずき・歌う（音節ごとに口の形）・ノリ・手を振る・首をかしげる。髪や服はバネで遅れてついてきます。拍・セクションの盛り上がり・歌詞の音節で動きます。
- 日本語: 「キャラは手を振って」「首をかしげて」「サビはキャラがノリノリで」
- 全身の立ち絵をパーツに分けて拍でカクカク踊らせる「立ち絵モーションMV」（ゲスト・テロップ・2周構成つき）は別の作り方です。スキル `mv-tachie-motion` を使います。キャラ・ゲスト・テロップは編集画面で直せます（[EDITOR_ja.md](EDITOR_ja.md)）。

## できないこと（正直に）
- After Effects のような実写のトラッキング（被写体に文字を貼り付ける）や、人物の後ろに文字を回り込ませる遮蔽（オクルージョン）はできません。
- 3D空間で文字の間をカメラが飛ぶ本格的な表現は簡易版のみ（既存の `fly3d` など）。
- 拍アクセントは BPM の拍グリッドからの近似です（キック・スネアの実音検出ではありません）。
- パーツアニメは2Dの切り絵です。振り向き・メッシュ変形・髪の物理演算・Live2D/Spine データの読み込みはできません。
- 自動分解はアニメ塗り・単純な背景で最も安定します。複雑な絵や実写は手で分けたパーツ（PSD）を使ってください。
