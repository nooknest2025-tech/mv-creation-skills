# レシピ：パーツアニメで踊るMV（全身リグ・カクカク振付・テーマ歌詞）

パーツに分けたキャラ1人（全身・肘と膝が曲がる）が、拍に合わせて **決めポーズへパッと切り替わる（12fps のポーズ・トゥ・ポーズ）** 振付で踊る、2Dポップな縦ノリMVの作り方です。
どの曲・どのキャラにも使えます。生成AIの動画は使いません（画像生成もしなくて作れます）。ぜんぶ編集画面で直せます。
テンプレート: [parts_dance_mv_template.json](parts_dance_mv_template.json)（`npm run recipe:dance` で当てはめ）

## 0. 流れ（コマンド）
```
# 1) キャラのパーツ（PSD / パーツPNG / rig.json）を input/parts に置いて、立ち絵プロジェクトを開く（最初の1回）
npm run editor -- --project <名前>
# 2) 腕・脚を肘・膝で分ける（腕が1枚・脚が1枚の素材のとき。関節に丸いパッド、腕を少し太く）
python scripts/rig_joints.py ../projects/<名前>/tachie/<rigフォルダ> --auto --thicken 1.2
# 3) 掛け声（Hey!/Ho!）の位置を分離ボーカルから探す（任意）
demucs --two-stems=vocals ../projects/<名前>/media/<曲>.mp3
python scripts/heyho.py separated/htdemucs/<曲>/vocals.wav --near 17,18.3 --out ../projects/<名前>/hits.json
# 4) レシピを当てはめる（元のファイルは *.before-recipe.json に残ります）
npm run recipe:dance -- --project <名前> --hits ../projects/<名前>/hits.json --title "曲名" --sub "SUB TITLE"
# 5) 編集画面で開き直して確認・調整 → チェック → 書き出し
npm run editor -- --project <名前>
npm run check:lyrics -- --project <名前>
python scripts/font_cover.py --project <名前> <使う書体の .ttf ...>
npm run qc:black -- <書き出したMP4>
```
低解像度の確認用書き出しは `MVPACK_SCALE=0.25`（編集画面の書き出し・`editor/export.mjs` 共通）。

## 1. キャラのリグ（パーツ）の決まり
| 部品（kind） | 親 | 中心（pivot） | メモ |
|---|---|---|---|
| hips（腰） | なし | 腰の中心 | 体の移動（左右・ジャンプ）は腰が持つ |
| leg_l / leg_r（太もも） | なし | 股関節 | `knee`（膝）と `foot`（足首）の座標を書く |
| shin_l / shin_r（すね） | 太もも | 膝 | 2本の骨のIKで、足を床に付けたまま膝が曲がる |
| foot_l / foot_r（靴） | すね | 足首 | すねと逆向きに少し回って床と平行を保つ |
| body（胴） | 腰 | 腰の上 | 腰でひねる・つぶれる |
| arm_l / arm_r（上腕） | 胴 | 肩 | |
| fore_l / fore_r（前腕） | 上腕 | 肘 | 肘の曲げ `el` / `er`（度） |
| hand_l / hand_r（手） | 前腕 | 手首 | `states.up` = 手を上げた時の絵（任意） |
| sleeve_l / sleeve_r（袖） | 上腕 | 肩 | `follow: 0`。**胴より手前**で肩の付け根を隠す |
| head / eye_* / mouth | 胴 / 頭 | | 口パク・まばたき |

- 画像は全部 **同じキャンバスサイズのPNG**（キャラ全体の絵の中の位置のまま）。rig.json に `legs: true`、`floorY`（床の高さ）、`shots`（全身・上半身・顔アップの大きさ）。
- 腕・脚が1枚の絵なら `rig_joints.py` で肘・膝で切ります。切り口には **関節の幅の丸いパッド**（中身の色・輪郭線なし）を先の側に入れるので、曲げても隙間も黒い輪も出ません。
- **腕を太く**: `--thicken 1.15〜1.3`。細い腕は踊ると「棒」に見えます。長さは変えず、腕の向きに直角な方向だけ広げます。

### 腕と袖の重ね順はポーズで変える（`rig.zArm`）
腕が体の横にある時と、体の前に来る時で、正しい重なりが逆になります。`rig_joints.py` が下の設定を入れます（手で書いても可）:
```json
"zArm": { "bend": 45,
  "front": { "arm": 7.4, "sleeve": 7.6, "fore": 7.7, "hand": 7.8 },
  "side":  { "arm": 5,   "fore": 4.9,  "hand": 4.95, "sleeve": 7.5 } }
```
- 前腕が `bend` 度より曲がっている（体の前に来る） → front: 胴 < 上腕 < 袖 < 前腕 < 手（手が胸の前に見える）。
- それ以外（腕が横） → side: 上腕・前腕・手は胴の後ろ、袖だけ胴の手前（肩の付け根を袖が隠す）。
- 数字は rig の z（胴=7 のとき）。胴の z が違うキャラは、それに合わせてずらします。

## 2. 振付（カクカク＝ポーズ・トゥ・ポーズ）
- 1拍に1ポーズ。次の拍頭で **12fps の1コマで切り替え**（なめらかに補間しない）。これが「2Dポップの強い演出」の正体です。
- ポーズは関節の角度で書きます（`stage.moves`）: `b` 胴の傾き / `bx` `by` 腰の移動 / `sq` つぶれ / `h` 首 / `l` `r` 腕を上げる角度 / `el` `er` 肘（+ = 前腕を内側・下に折る、− = 前腕を上に＝顔の横へ） / `hr` 腰の回転 / `sl` `sr` 足の左右 / `fl` `fr` 足を上げる。
- 区間ごとの並び（`stage.routine`）: `intro` / `verse` / `pre` / `chorus` に `[ポーズ, 拍]` を並べます。テンプレートに22ポーズ（腰に手・猫の手・ロボット・力こぶ・指さし・胸に手・ツメ・のぞき・突き上げ・ジャンプ…）が入っています。
- 最後: `stage.finale` の決めポーズで止める。`stage.freezeAt`（秒）で **画面全体（背景・粒子・カメラ）** がその秒で止まります（歌詞の終わりや `stopAt` より優先）。`hideLyricsAtStop: true` で止まった後は歌詞を出しません。
- **振付パネル**: 編集画面の「立ち絵」パネルの「振付・Hey!/Ho!（全体）」で、見せ場（hits）・並び（routine）・ポーズ（moves）を JSON で直せます。カットごとの構図・背景・カメラも同じパネルにあります。
- 顔アップ・上半身のカットでも振付は続きます（上半身だけ見える）。上半身で手が文字に被りやすいポーズ（腰に手）は、下に歌詞がある行の間だけカメラを少し引きます（レシピが自動で `cam.s 0.86 / y -0.07`）。

### 掛け声（Hey! / Ho!）
- `stage.hits`: `{ t: 秒, move: ポーズ, beats: 保つ拍, text: "Hey!", x, y, size, color }`。その瞬間にポーズへ飛び、ギザギザの吹き出しで文字が叩きつけられ、集中線とズームパンチが入ります。
- 時刻は分離したボーカルから: `heyho.py --near だいたいの秒,…`（その近くの「ボーカルが一瞬落ちて強く立ち上がる」所に合わせる）。区間だけ分かる時は `--from --to --count`。
- 歌詞の（Hey!）のような括弧の掛け声と、hits の文字が両方出ると二重になります。hits を使う時は `stage.callBubbles: false`（レシピが設定）。

## 3. カット（構図）
カットごとに `scene.stage.layout`: `full` 全身 / `bust` 上半身 / `face` 顔アップ / `trio` 3人並び（同じキャラ×3、両脇は半拍遅れ） / `split` 斜め分割。背景は `cutBg`（sunburst / rings / checker / stripes / halftone / grid、背景画像があれば image-dots / image-rays / image-grid）。
テンプレートは区間の種類ごとに拍数のパターンを持ち、曲の区間に沿って並べます（Aメロ 2〜4拍、サビ 1〜3拍。0.45秒未満のカットは前のカットにまとめる）。

## 4. 歌詞（テーマ付きの縦書き／下帯・行ごとの置き場所）
- 歌詞の見た目「ハロウィン（よけ配置・ゆらゆら）」= `stageStyle: "hw"`。1文字ずつ歌ったタイミングでポンと出て、ゆらゆら揺れ、拍で弾み、板（プレート）と飾り（かぼちゃ・こうもり・おばけ・クモの巣・ろうそく）が付きます。下帯の時は文字がたれます。
- **置き場所は行ごとに1つ**: `stage.hwLyrics[行id] = { place: "side" | "bottom", side: "l" | "r", font, color, deco }`。
  レシピは、その行がまたぐ **全部のカット** を見て1回だけ決めます（3人並び・斜め分割を1つでもまたぐ → 下帯。それ以外 → 左右の縦書き、行ごとに左右交互）。カットが変わっても文字は動きません。
- **編集画面で直接動かせる**: 歌詞パネルの「プレビュー上で歌詞をドラッグして移動」（または Alt を押しながらドラッグ）。位置は行に保存され（x, y）、どのカットでも同じ場所。「この行の位置を自動に戻す」で元へ。
- 書体: pop（Mochiy Pop One）/ spooky（Reggae One）/ potta（Potta One）/ dela（Dela Gothic One）。**使う前に `font_cover.py` で歌詞の字が全部入っているか確認**（漢字の少ない飾り書体は□や別書体になります）。
- テーマ替え: `stage.hwTheme = { colors: [[文字, 縁, 光], …], fonts: { id: "CSSの書体名" } }`。飾りは `deco` に2つまで。
- マスコット（`stage.floaters`）は歌詞の箱と重なると、反対側 → 上の隅へ自動で逃げます（全部ふさがっていればその間だけ隠れる）。

## 5. タイトル
- `scene.stage.title = { text, sub, start, end, y, size }`。**全文を一度に出し**（タイプライター表示はしない）、帯の幅に自動で縮めて収めます。縁取りは丸い角で塗りの下に描くので、細い字（ミ・ニ など）がつぶれません。
- レシピは最初のカット（〜1.2秒）と、止める直前の最後のカットに入れます。

## 6. チェック（書き出し前に必ず）
| チェック | コマンド | 合格 |
|---|---|---|
| 歌詞の重複・行の位置 | `npm run check:lyrics -- --project <名前>` | 重複 0 / 1フレーム最大1行 / 行の途中で位置が変わる行 0 |
| 書体に字があるか | `python scripts/font_cover.py --project <名前> <ttf…>` | 足りない字 0 |
| 黒い画面 | `npm run qc:black -- <MP4>` | failed 0 |
| 目で見る | 低解像度で書き出し → 1秒ごとのコンタクトシート | 下の「失敗例」が無いこと |

## 7. 失敗例と直し方（実際にあったもの）
| 見え方 | 原因 | 直し方 |
|---|---|---|
| 肩がブレて見える・袖が胴の後ろに消える | 袖が胴より奥、または袖が腕と一緒に回っていた | 袖は上腕の子・`follow: 0`・胴より手前（z 7.5）。腕の重ね順は `zArm` でポーズごとに |
| 胸の前に手が浮いている／腕が胴に埋まる | 前腕を体の前に折ったのに腕が胴の後ろのまま | `zArm.front`（前腕が bend 度より曲がったら腕全体を胴の手前へ） |
| 腕が棒のようで硬い・腕だけ細い | 腕1枚で肘が無い／細い | `rig_joints.py --auto --thicken 1.2`。顔の横に手を上げるポーズは `el` をマイナスに |
| 膝が曲がらず、しゃがむと脚が縮む | 脚1枚・膝なし | 膝で分けて `knee` を書く（2本の骨のIK） |
| 顔が二重に見える | 古い歌詞の見た目（後ろに大きく・半透明）が重なっていた／同じ行が2つ描かれていた | 舞台の歌詞は1フレーム最大1行（自動）。掛け声の吹き出しと hits を両方出さない。`check:lyrics` |
| シーンが変わると歌詞が別の場所に出る | 置き場所をカットごとに決めていた | 置き場所は行ごと（hwLyrics の place / side、編集画面のドラッグ）。`check:lyrics` の「行の途中で位置が変わる行」が 0 |
| 字が□・ブロックになる | 書体に漢字が無い | `font_cover.py` で確認して別の書体に |
| タイトルが途中まで（「タイト」）で止まる／太字でつぶれる | 1文字ずつ出す表示のまま最後のコマで止まった／太字の合成 | タイトルは全文を一度に・幅に自動で収める（このパックの標準） |
| マスコットが歌詞に隠れる | マスコットの位置が固定 | 歌詞の箱をよける（hw 歌詞なら自動） |
| 最後に歌詞が残ったまま止まる | 止める秒が無い | `freezeAt` と `hideLyricsAtStop: true` |
