# MV制作パック（Codex 用・日本語）

バージョン: 2.0.0（変更点は [CHANGELOG.md](../../CHANGELOG.md)）

曲を入れて **ダブルクリック1回** で、歌詞が動くMV（MP4）ができる道具一式です。
OpenAI Codex に入れると、**日本語で話しかけるだけ**で「サビはグリッチで」「縦長にして」のような直しもできます。
既定は**全部無料**（PCの中で処理）。有料の生成AIは、使うときだけ金額を見せて確認してから。

- **まず `doctor.bat` / `./doctor.sh`**: 足りないアプリ（Node.js・ffmpeg・Python…）を日本語で説明し、1つずつ確認してインストール。料金（無料/無料枠あり/有料）も表示 → [docs/SETUP_GUIDE_ja.md](docs/SETUP_GUIDE_ja.md)
- **歌詞アニメーション 81種**（`npm run styles` とエディターの一覧と同じカタログ）: 基本34（32＋桜吹雪・スポットライト）＋合流・分かれ4＋合成モーションで作ったムード別32（バラード・弾き語り・シティポップ/lo-fi・和風・ヒップホップ・アイドル・ロック・ダーク/ボカロ・チル）＋pro-motion 11（`pro_*`）＋語エフェクト9
- **start は1問ずつ・Enter でおすすめ**: Q1 何がありますか？（曲と歌詞だけ（SRT/LRC/JSON等もOK）／＋画像／＋動画素材／＋キャラ素材。input フォルダから自動で選択済み）→ Q2 映像はどうする？（文字と図形だけ＝文字PV 0円／画像だけで作る／動画も入れる／画像を作る＝無料の手作業 or 有料・枚数と金額の目安つき／立ち絵で作る。素材に合うものだけ）→ Q3 ここから先は？（おまかせ／半自動／こだわり。1・2 に合う選択肢だけ）→ 画面の形 → 確認画面（素材・作り方と理由・費用）→ Enter で開始。曲と歌詞だけなら全部 Enter で文字PV（0円）
- **自分で作る → 入れるだけ（無料）**: 画像・動画は好きなアプリで作って `input/made/` に入れ、`npm run made`（「作ったの入れた」）で自動でシーンに割り当てて作り直し。シーンごとのプロンプトと添付画像（役割と場所つき）を画面とファイルで渡します。有料は MCP・生成APIにつなぐときだけ（直前にプロンプト・添付・見積もりを見せて毎回確認）
- **文字PVの図形レイヤーも編集画面で**: 図形・線・粒・区切りの転換を、動画全体／シーンごとに オン・オフ・種類・色・強さ・速さ・量 で直せる（元に戻すも可）。直さなければ `npm run mv` と同じ絵
- **編集画面（エディター）で後から全部直せる**: 歌詞の結合・分割・秒数、シーン、カメラの動き32種・エフェクト26種、全モーション・書体・色、立ち絵のキャラ・ゲスト・テロップまでブラウザで直して、保存した内容で MP4 を書き出し。どの作り方でも（文字PVも）編集画面用のプロジェクトができ、自動で作った見た目は「既定値」でエディターの変更が必ず優先 → [docs/EDITOR_ja.md](docs/EDITOR_ja.md)
- **立ち絵モーションMV**: 全身キャラの立ち絵をパーツに分けて拍に合わせて踊らせる（ボカロ・ゆっくり系のパーツアニメ）。口パク・歌詞レイアウト（縦書き吹き出し・後ろに大きく・下の帯 など）・ゲスト演出・2周構成。`start` の「映像はどうする？」で「立ち絵で作る」を選ぶか（キャラ素材があると最初から選ばれています）、「立ち絵で」「立ち絵＋タイポグラフィで」のように日本語でも指定できます（ほかの見せ方と組み合わせ可）。キャラ素材は `input/parts/`（パーツPNG・PSD）か `input/tachie/`（PSD・全身の立ち絵1枚）。スキル `mv-tachie-motion`
- **曲と画に「合う」自動演出**: ジャンル/BPM/盛り上がり/言葉の速さ と 画像解析（顔・ごちゃつき・明るさ）で点数付け。バラードに揺れ・グリッチは出さない、文字は顔を避けて読める色に。選んだ理由をセクションごとに日本語で表示。「別パターンで」「リリックは統一感重視/変化多め」
- **ハイブリッド構成12種**: 「ストーリー＋リップシンクで」「サビだけ歌うシーン」「ライブと回想で」など。セクションごとに歌唱/物語/ダンス/文字主役…の割合を決め、カメラ・画像・生成プロンプトに反映
- **プロのモーション（pro-motion）**: expo-out・バネ・ポーズtoポーズ、マスクで出入り、要の語は大きく助詞は小さく、3×3グリッドと対角の流れ、セクションごと3〜4色、拍で反転フラッシュ。モーショングラフィックス（図形・同心円・粒・図形トランジション・UI風パララックス）も選べます → [docs/PRO_DIRECTION_ja.md](docs/PRO_DIRECTION_ja.md)
- **半自動モード**: `start` の2番。見せ方（複数OK: ダンス＋リリックモーション・立ち絵＋タイポグラフィ 等）・画像テイスト・シーンの細かさ（約カット数）・動画化（費用の目安）・リリックの雰囲気・キャラの動きを、おすすめ既定値つきで6問だけ。最後に計画を確認してから作ります
- **パーツアニメ**: `npm run parts -- import キャラ.psd`（PNG フォルダ／1枚絵の自動分解 split も可）→ 支点・親子を自動推定 → 待機・うなずき・歌う・ノリ・手を振る・首かしげ。「キャラは手を振って」で指定
- **プロチェック**: 書き出し前に「同じ動きの連続・大技の出しすぎ・読めない文字・拍ずれ・盛り上がりの山なし」を点検し、自動の所は直し、ユーザー指定の所は**変えずに提案だけ**（演出メモ `director_note.md`）→ [docs/PRO_DIRECTION_ja.md](docs/PRO_DIRECTION_ja.md)
- **新しい動きを Codex に頼める**: 「花びらみたいに舞い落ちる字」と言えば、Codex がスキル `mv-style-create` の手順で雛形作成 → 実装 → テスト → 静止画と短い動画で確認（`npm run style:new`）。作成例: 桜吹雪 `sakura_fall`・スポットライト `spotlight`
- **書体111種（無料・再配布OK、OFL/Apache。同梱は13種、残りは使う時に自動ダウンロード）**: 明朝 / ゴシック / 丸ゴシック / 手書き / 筆・和風 / ポップ / デザイン・レトロ / 欧文。「サビは筆文字で」「丸っこい字に」「『キライ』は極太で」で、曲・セクション・行・言葉ごとに指定 → [docs/FONTS_ja.md](docs/FONTS_ja.md)
- **ジャンル別レシピ**（バラード / ロック・EDM / シティポップ・ジャズ / アイドル・ポップ / 和風 / ヒップホップ）: 動き・書体・色をまとめて自動選択
- 6つのジャンル演出（ストーリー / ダンス / リップシンク / ライブ / ボカロ / ファーストテイク風）を曲から自動で選択
- 画像だけでも派手に（疑似2.5Dの奥行き・Ken Burns・光漏れ・粒子・拍に合わせた揺れとトランジション・セクションごとの色）
- 動画素材は良い場面を自動で探してビートで切る。スピードランプ（パンチ・スロー・加速）もショットごとに
- **キャラが動く**：目パチ・歌詞に合わせた口パク・呼吸・髪揺れ・拍でノる（Remotion 内で。ショットごとに「S012は口パクなし」）
- **音に反応する映像**（TouchDesigner 風を Remotion だけで）：プラズマ／トンネル／波紋／フロー背景、スペクトラム（棒・リング・波）、低音で湧く粒子、フィードバックの残像
- **仕上げも Remotion 内で**：グレード・フィルムグレイン・グロー／ハレーション・周辺減光・色収差・シネスコ黒帯
- 動画生成は **どの MCP でも**（Pollo・Grok・Runway…）→ [docs/VIDEO_MCP_ja.md](docs/VIDEO_MCP_ja.md)
- 16:9（4K も可） / 9:16 / 1:1 / 4:5、サビだけの縦ハイライト
- DaVinci Resolve 用（透過の歌詞レイヤー＋FCPXML）、Drive 用の 100MB 未満版
- 元の音声は一切いじらない（自動で md5 チェック）

## Codex への入れ方
1. このフォルダ（`MV_SKILL_PACK`）を好きな場所に置く（例: `C:\Users\あなた\MV`）。
2. Codex をこのフォルダで開く（CLI なら `cd` してから `codex`）。
   - `AGENTS.md`（ルールと日本語→設定の対応表）と `.agents/skills/` の16スキルを Codex が自動で読みます。
   - どのフォルダからでも使いたい場合は `.agents/skills/` の中身を `~/.agents/skills/` にコピー（Codex の個人用スキルの場所）。
3. `setup.bat` をダブルクリック（または Codex に「セットアップして」）。

## クイックスタート（5ステップ）
1. `setup.bat` をダブルクリック（初回だけ・数分）
2. `input/` に曲を入れる（歌詞・画像・動画はあれば）
3. `start.bat` をダブルクリック → 「半自動」で Enter（質問は6つ。全部 Enter でもプロのおすすめで作れます）
4. プレビュー静止画を見て Enter → MP4 ができる（`projects/<曲名>/out/`）
5. 直したい所を Codex に日本語で伝える → もう一度 `start.bat`（v2 ができる。前の版は残る）

## 共通編集UI（ブラウザで直して書き出す）
歌詞の結合・分割・秒数、シーンの切替・画像位置、モーション（pro_* を含む全カタログ）・書体・色をブラウザで直し、保存した内容で MP4 を書き出せます。どの曲のプロジェクトでも使えます。
```bash
cd remotion
npm run editor -- --demo --project editor-demo   # 見本で試す
npm run editor -- --project <曲名>               # npm run mv で作った画像MVを開く
```
→ 詳しくは [docs/EDITOR_ja.md](docs/EDITOR_ja.md)（確認済み・未確認の範囲も書いています）

## 6つのジャンル演出（プリセット）
曲の BPM・音の強さ・歌詞の密度から自動で選びます。「ボカロっぽく」などの日本語で変更できます。

比較動画は `npm run presets-demo -- --project <曲名>` で作れます。

| プリセット | カットの速さ | 画面の作り・カメラ | 特徴 |
|---|---|---|---|
| ストーリー `story` | イントロ/Aメロ8拍・サビ2拍 | シネスコ黒帯、歌詞は下の帯に小さめ、サビはなめらかランプ | 物語。グロー・ハレーション・フィルム粒子 |
| ダンス `dance` | サビ1拍・Aメロ2拍 | 歌詞は下寄り大きめ、サビはパンチランプ、Bメロは加速 | 低音で湧く粒子・スペクトラム棒・色収差 |

## 口パク・ダンスの尺合わせ（要点）
- 採用した口パク・ダンスのクリップは、元の曲の該当位置にぴったり置きます。長さが1フレームを超えてずれていたら止めます。音声は元の曲1本だけで、クリップの音はミュートします。
- 短すぎて対応尺に1秒以上伸びるショットは警告し、結合・モデル変更・長めに作って切る、の3案を出します。あなたが指定したカットは自動で変えません。
- 「S05を元の長さに戻して」か `npm run timing -- restore S005`（全部なら `restore all`）で元に戻せます。ファイルは消しません。詳しくは docs/VIDEO_MODELS_ja.md。

### 生成AI（任意・有料もあり）
- 無料: Grok アプリ / grok.com / Gemini アプリなどで手動生成 → `input/` か `gen/takes/<ショットID>/` に入れる。プロンプトは `npm run gen -- plan` が `prompts.csv` に書き出します。
- MCP（Pollo・Grok・Runway・Kling など何でも）: `npm run gen -- plan --provider pollo` → `gen_tasks.json` を Codex が MCP で実行 → `gen -- import` → `gallery`。手順: [docs/VIDEO_MCP_ja.md](docs/VIDEO_MCP_ja.md)
- 有料 API: `gen/models.yaml` に**公式ページで確認した価格だけ**を出典と確認日つきで登録（xAI Grok Imagine、Runway、Pollo AI API（Pollo 2.5・Kling 3.0 Omni・MiniMax H3）。Pollo のアプリ/MCP クレジットのドル換算は未確認。Google Veo 3.1 Preview は 2026-10-22 終了と記載、Gemini Omni は価格未確認）。見積もり（$/秒 × 秒 × テイク数）に OK した金額を `--confirm` で渡さないと実行されません。
- モデル選びの目安（Codex 側）: [docs/MODEL_ROUTING_ja.md](docs/MODEL_ROUTING_ja.md)

### Windows メモ
- DaVinci Resolve 21: `--davinci` で `*_lyrics_overlay.mov`（透過）と `*.fcpxml` → ファイル › 読み込み › タイムライン。
- ffmpeg が無くても Remotion 同梱の ffmpeg を自動で使います。速くしたいなら `winget install Gyan.FFmpeg`。
- 歌詞の自動書き起こしは Python と `pip install faster-whisper` が必要（無くても歌詞ファイルがあれば不要）。

### 目パチ・口パクの準備（任意）
- 顔の自動検出に Python と `pip install "opencv-python-headless<5" numpy` が必要（OpenCV 5 は検出器が無いので 4.x）。別の Python を使うなら環境変数 `MVPACK_PYTHON` にパス。
- 自動検出はアニメ顔の正面向き向け。斜め顔などでずれたら `npm run faces` でクリック指定（保存すると次回から優先）。顔が無い画像は呼吸・揺れだけ。

## まだできないこと・未確認のこと（正直に）
- 「合う」判定は手作りの点数表（スタイルごとの強さ・ムードタグ・禁止ルール）です。学習モデルではないので、好みと違えば「別パターンで」かスタイル指定を。
- 画像解析は上・中・下3帯の明るさ/ごちゃつきと顔の位置だけ。被写体の向き・視線の先までは見ていません。画風判定（イラスト/写真/水彩）は簡易。
- ハイブリッド構成は「どの画像をどの役割に回すか」を決めますが、手持ち画像に歌唱シーンが無ければ歌唱カットは作れません（顔の画像か生成 MCP が必要）。
- ムード別32スタイルは共通の部品の組み合わせなので、基本スタイルほど凝った専用演出ではありません。一部（囁き・ローファイ）は暗い背景だと薄く見えます。
- 料金は 2026-10-27 時点の公式ページの値。Pollo は公式ページを自動取得できず未確認。
- doctor の自動インストールは Linux でのみ実機確認（winget / brew のコマンドは公式の ID を使っていますが Windows/Mac 実機は未確認）。
- ジャンルの自動判定は BPM・言葉の数・和の漢字の割合だけで決めています。外れたら「ジャンルは○○で」と指定してください。
- 色（パレット）が変わるのは、標準の白・クリーム・黄・ピンクで描く文字だけです。ネオン・ハンコ・ダイアログなど、色が決まっているスタイルはそのままです。
- 言葉ごとの書体は、1文字ずつ描くスタイル（多くのスタイル）でだけ効きます。カラオケ塗り・積み上げなど、語や行をまとめて描くスタイルでは効きません。
- 新しいスタイルの実装は Codex が書くので、出来は頼み方と確認次第です。`style:check` の静止画は必ず目で見てください。
- Windows 11 実機で、編集画面と MP4 書き出しの動作を確認済み（2026-10）。それ以外（setup.bat / start.bat の通し、doctor の自動インストールなど）の Windows 実機確認と、macOS 実機での確認はまだです。
- 有料 API（xAI）の自動実行は、リクエストを組み立てるところまでで、実際の送信は未テスト。
- 1枚絵の顔の口パクは「口の周りを縦に伸ばす」方式で、口の形（あ・い・う…）の描き分けはしません。パーツに分けたキャラ（`npm run parts` のパーツアニメ、立ち絵モーションMV）なら、音節ごとの口の形や拍で踊る動きも出せます。
- 顔の自動検出は斜め顔・小さい顔でずれやすい → `npm run faces` で手で指定。
- Pollo などの MCP は手順と取り込みまでを確認。実際に有料生成を呼ぶところは未テスト。
- 自動書き起こしは誤字が出ます。歌詞テキストがあれば .txt で渡すのがおすすめ（位置合わせは約0.5秒以内のずれを確認済み。1行だけ約1.3秒ずれた例あり → エディタで修正）。
- BPM の自動検出は外れることがあります → 「BPMは○○」で固定。
