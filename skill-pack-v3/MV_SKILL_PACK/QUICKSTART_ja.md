# はじめての人向け — 3ステップでMVを作る

むずかしい設定はありません。**入れる → ダブルクリック → できあがり** です。

（最初の1回だけ: `setup.bat` をダブルクリック。Node.js が無いと言われたら表示どおりに入れてください）

## ① `input` フォルダに入れる
曲を1つ入れるだけでOK。あれば歌詞や画像も。

| 持っているもの | どうなる |
|---|---|
| 曲だけ | 歌詞を自動で書き起こし（無料・PC内で処理）、画は曲に反応する抽象映像 |
| 曲＋歌詞テキスト（.txt） | 歌詞を音に自動で位置合わせ |
| 曲＋字幕ファイル（.srt / .lrc / .vtt / .ass） | そのまま使う |
| 曲＋歌詞同期JSON | そのまま使う（いちばん正確） |
| ＋画像（jpg/png） | 画像に動き（ズーム・奥行き・光・粒子・拍の揺れ）をつけて使う |
| ＋動画（mp4/mov） | 良い場面を自動で探してビートに合わせて切る |
| ＋`stems/vocals.wav` | 書き起こしがより正確に |

何も持っていない？ → そのまま ② へ。**サンプル（曲・歌詞・画像8枚）で試せます。**

## ② `start.bat` をダブルクリック
質問は2つだけ（どう作るか・画面の形）:
```
Q1. どう作りますか？
  1) おまかせ（全部自動・おすすめ）
  2) ジャンルを選ぶ（ストーリー / ダンス / リップシンク / ライブ / ボカロ / ファーストテイク風）
  3) こだわり（細かく指定）
Q3. 画面の形は？ 1) 横長 16:9  2) 縦長 9:16  3) 正方形  4) 4:5  5) 全部
```
迷ったら **両方 Enter**（おまかせ・横長）。始める前に「何を使って、何を自動で補うか」が日本語で表示されます。
足りないファイルや壊れたファイルがあると、**何が問題で、どう直すか**を日本語で教えてくれます。

## ③ プレビューを見て、OKならMP4
まず静止画のプレビューが出ます（冒頭・サビ・中盤・エンディング・サムネ候補）。

<img src="docs/images/qs_preview_01_冒頭フック.jpg" height="260"> <img src="docs/images/qs_preview_02_最初のサビ.jpg" height="260">

良ければ Enter → MP4 ができます。場所は `projects/<曲名>/out/`（終わるとフォルダが開きます）。
- `<曲名>_v1_16x9.mp4` … 本番用
- `<曲名>_v1_16x9_drive.mp4` … Google Drive 等に上げやすい 100MB 未満版
- `<曲名>_v1_QA.md` … 自動チェックの結果

## 直したいときは
Codex に日本語で言うだけ: 「サビはグリッチで」「縦長にして」「歌詞を0.2秒早く」「ボカロっぽく」「目パチと口パクして」「TouchDesigner風の背景」「シネスコの黒帯」「サビはスピードランプ」。
もう一度 `start.bat` で新しい版（v2）ができます。前の版は消えません。
