# はじめての人向け — 3ステップでMVを作る

むずかしい設定はありません。**入れる → ダブルクリック → できあがり** です。

（最初の1回だけ: `setup.bat` をダブルクリック。Node.js が無いと言われたら表示どおりに入れてください）

## ① `input` フォルダに入れる
曲を1つ入れるだけでOK。あれば歌詞や画像も。

| 持っているもの | どうなる |
|---|---|
| 曲だけ | 歌詞を自動で書き起こし（無料・PC内で処理）、画は曲に反応する抽象映像 |
| 曲＋歌詞テキスト（.txt） | 歌詞を音に自動で位置合わせ |
| 曲＋字幕ファイル（.srt / .lrc / .vtt / .ass） | そのまま使う |
| 曲＋歌詞同期JSON | そのまま使う（いちばん正確） |
| ＋画像（jpg/png） | 画像に動き（ズーム・奥行き・光・粒子・拍の揺れ）をつけて使う |
| ＋動画（mp4/mov） | 良い場面を自動で探してビートに合わせて切る |
| ＋`stems/vocals.wav` | 書き起こしがより正確に |

何も持っていない？ → そのまま ② へ。**サンプル（曲・歌詞・画像8枚）で試せます。**

## ② `start.bat` をダブルクリック
1画面に1問ずつ聞かれます。**Enter だけで ★おすすめ** が選ばれ、input フォルダの中身から答えを先に選んであります。曲と歌詞だけなら、全部 Enter で文字PV（0円）ができます。
```
🔎 見つかった素材: 曲 あり / 歌詞 あり / 画像 0 枚 / 動画 0 本 / キャラ素材 0 人

Q1. 何がありますか？（見つかった素材から選んであります）
  1) 曲と歌詞だけ（SRT/LRC/JSON等の歌詞データもOK） ★おすすめ
  2) ＋画像
  3) ＋動画素材
  4) ＋キャラ素材（立ち絵・パーツ）

Q2. 映像はどうする？
  画像がないので、まずは文字と図形で作る「文字PV」がおすすめです（0円）
  1) 文字と図形だけ（文字PV・0円） ★おすすめ
  2) 画像を作る（無料の手作業 or 有料：約○枚。手作業なら0円／有料なら約$○）

Q3. ここから先は？
  1) おまかせ ★おすすめ … 追加の質問なし
  2) 半自動 … 見せ方・ジャンル・シーンの細かさ・歌詞の雰囲気などを数問
  3) こだわり … 決めることごとに、おすすめ2〜3案を理由つきで比べる

Q4. 画面の形は？ 1) 横長 16:9 ★おすすめ  2) 縦長 9:16  3) 正方形 1:1  4) 4:5  5) 全部

📋 この内容で作ります（Enter で開始 / n でやめる）
  素材・映像（作り方と理由）・進め方・画面・費用・できあがり（MP4＋編集画面用プロジェクト）
```
- Q2 の選択肢は Q1 の素材に合うものだけです。画像があれば「画像だけで作る」、動画があれば「動画も入れる」、キャラ素材があれば「立ち絵で作る」がおすすめになります。「画像を作る」は作り方リスト（無料の手作業でOK）を用意するだけで、**有料APIは金額を確認してからしか使いません**。
- 半自動・こだわりは、Q1・Q2 に合う質問と選択肢だけが出ます（画像がないのに画像前提の構成は出ません。ジャンルもここで選べます）。
- **立ち絵モーションMV**（キャラの立ち絵をパーツに分けて、拍で踊らせる・口パク）にしたいときは、キャラ素材を `input/parts/`（パーツPNG・PSD）か `input/tachie/`（PSD・全身の立ち絵1枚）に入れてください。Q1 が「＋キャラ素材」、Q2 が「立ち絵で作る」になります。ほかの見せ方（タイポグラフィ・物語 など）とも組み合わせられます。仕上げと MP4 の書き出しは編集画面で行います。
- どの道でも、できあがりは MP4 と**編集画面用のプロジェクト**（文字PVでも）。あとから全部直せます。
足りないファイルや壊れたファイルがあると、**何が問題で、どう直すか**を日本語で教えてくれます。

## ③ プレビューを見て、OKならMP4
まず静止画のプレビューが出ます（冒頭・サビ・中盤・エンディング・サムネ候補）。

<img src="docs/images/qs_preview_01_冒頭フック.jpg" height="260"> <img src="docs/images/qs_preview_02_最初のサビ.jpg" height="260">

良ければ Enter → MP4 ができます。場所は `projects/<曲名>/out/`（終わるとフォルダが開きます）。
- `<曲名>_v1_16x9.mp4` … 本番用
- `<曲名>_v1_16x9_drive.mp4` … Google Drive 等に上げやすい 100MB 未満版
- `<曲名>_v1_QA.md` … 自動チェックの結果

## 直したいときは
Codex に日本語で言うだけ: 「サビはグリッチで」「縦長にして」「歌詞を0.2秒早く」「ボカロっぽく」「目パチと口パクして」「TouchDesigner風の背景」「シネスコの黒帯」「サビはスピードランプ」。
もう一度 `start.bat` で新しい版（v2）ができます。前の版は消えません。

## 編集画面で自分で直す
作り終わると「いま編集画面を開きますか？ [Y/n]」と聞かれます。Enter で、ブラウザの編集画面（`http://127.0.0.1:5195/editor.html`）が使えます。歌詞の秒数・結合・分割、シーン、カメラ・エフェクト、モーション・書体・色などを直して、保存した内容で MP4 を書き出せます。自動で作った見た目は「既定値」で、ここで直した所が必ず優先されます。
あとから開くときは `remotion/` で `npm run editor -- --project <曲名>`。詳しくは [docs/EDITOR_ja.md](docs/EDITOR_ja.md)。
