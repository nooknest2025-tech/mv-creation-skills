# 立ち絵モーションMV（パーツアニメで踊らせる）

全部 Remotion ＋ Python（OpenCV）で作る。**有料の生成は使わない**（使うときは見積もりを見せて OK をもらってから）。
実例：`projects/パーツアニメ試作/`（ミスターヘンドレ。v2→v6.6 で固まった作り方）。

- 描画: `remotion/src/render/Tachie.tsx`（ステージ・歌詞・ゲスト）、`remotion/src/lib/tachie.ts`（ポーズ・口パク・停止時刻）
- ステージ定義: `projects/<曲>/tachie/*.tachie.json`（キャラ・背景・色・読み・ゲスト・ループ範囲）
- パーツ作成スクリプト例: `projects/パーツアニメ試作/tachie/parts5.py`・`cafe.py`・`mouths.py`・`guests.py`
- エディター取り込み: `remotion/scripts/editor.ts`（起動のたびに tachie 定義とリグを読み直す）

## 0a. ウィザード・日本語の指示から作る（標準の入口）
- `npm run start` の4つの作り方すべてで選べる: おまかせ（キャラ素材があれば自動で「立ち絵＋リリックモーション」）／半自動（見せ方の「立ち絵モーション」か、キャラの動きの「立ち絵モーションMVにする」）／ジャンル（キャラ素材があると「立ち絵にしますか？」）／こだわり（構成の比較に「立ち絵モーションMV」）。
- 日本語: 「立ち絵で」「パーツアニメで」「キャラを踊らせて」。ほかの見せ方と組み合わせ可（「立ち絵＋タイポグラフィで」「立ち絵＋物語＋モーショングラフィックスで」）。設定は `combo` に `tachie`。
- 素材の探し方（`scripts/tachie_project.ts`）: `projects/<曲>/parts/*/rig.json` と `input/parts/*/rig.json`（取り込み済み）→ `input/parts/`・`input/tachie/` の PSD → `input/parts/<名前>/` のパーツPNG → `input/tachie/` の全身1枚（自動分解・粗い）。取り込みは `npm run parts` と同じコード。最大3キャラ。`input/parts/`・`input/tachie/` の画像はシーン画像としては使わない。
- 作るもの: `projects/<曲>/tachie/main.tachie.json`（既にあれば上書きしない）と `rig_<名前>/`、`out/editor-input.json`。立ち絵のカット・文字だけのカットは立ち絵ステージ、物語などのカットは手持ち画像。MP4 は編集画面の「MP4を書き出す」で作る（エディターでの変更が必ず優先）。
- 素材が無いときは、入れる場所と形式を日本語で表示して止まる（`TACHIE_MATERIAL_HELP`）。ゲスト・浮かぶステッカー・2周構成は、下の手順で `main.tachie.json` に足す。

## 0. 進め方（初心者向けの順番）
1. 素材の確認 → パーツ分け → **重ね合わせ確認（元絵と並べる）** をしてからユーザーに見せる。
2. 静止画（数秒ごと）と並べたコンタクトシートで確認 → エディターで通し確認 → **MP4 は最後**。
3. 版ごとに `tachie_vXX` とデプロイzipを残す（戻せるように）。git の commit / push はユーザーの OK があるときだけ。

## 1. キャラの準備とパーツ分け
- 素材は **正面・全身・腕を下ろした立ち絵**（Tポーズではなく、元絵の自然な腕のまま）。白背景なら境界から塗りつぶしで抜き、縁の白フチ（フリンジ）を消す。**元解像度のまま**切る。
- パーツ: body / head / arm_l / arm_r（＋ guitar・staff などの小道具）/ eye_l・eye_r（open / half / closed）/ mouth（closed / i / a）。全部「キャンバス全面サイズの透明PNG（webp）＋ pivot ＋ parent ＋ z」で `rig.json` に書く。
- **腕は肩の縫い目で切り、袖を丸ごと腕パーツに入れる**（袖の途中で切ると、上半分が体に残って細い肩・浮いた腕になる）。
- **肩キャップ（丸い肩・袖の上部）は元絵の画素で体側の固定パーツにし、腕より上に重ねる**（`cap_l`/`cap_r`, z を腕より上）。腕はその下で回るので関節が見えない。pivot はキャップの中心＝肩関節。
- 腕を外したあとの体の側面は、シャツの色で埋めて輪郭線を引き直す（穴・段差を残さない）。
- 耳・帽子の飾りは head に入れる。後ろ髪を頭パーツに混ぜない（首を振ったときに髪が切れる）。
- 白い縁取り（ステッカー風）は **パーツごとではなく全体シルエットに1回だけ**（`drop-shadow` を4方向＋影）。
- 黒い服の上に黒い腕など、黒×黒で見えなくなる所は細い縁（リム）か線で分ける。ただしグレーの線が「余計な線」に見えたら外す（肩キャップ方式なら不要）。
- 腕の振り幅はキャラごとに制限する（`rig.json` の `armRange`・`armScale`。例：カフェの子は `armScale: 0.6`, `armRange: [-15, 60]`）。大きすぎると常にTポーズに見える。
- 見せる前に必ず: 元絵との重ね（安静ポーズで差がほぼ0）、腕を 20°/40°/60° 回した拡大比較、実際のカットの静止画。

## 2. 目パチ・口パク
- 口は **元絵の口の線から開く**（同じ幅・同じ位置）。closed＝元の線、i＝半開き、a＝全開。別の口を描き足さない。継ぎ目の線が出たら消す。
- 目は open / half / closed。まばたきの前後に half を1コマ入れると自然。
- 口の開閉 = 歌詞のモーラ（文字）タイミング × ボーカル帯（300–3000Hz）の音量（`stage.vocal`）。漢字は読みがずれるので `readings`（歌詞→かな）をステージに書く。
- 歌う人の指定は `singerIdx`（行番号ごと: `"black"` / `"black,cafe"` / `"all"`）。

## 3. ダンス（ほしあき系のカクカク）
- 動きはサイン波ではなく **決めポーズを拍で切り替える pose-to-pose**。`MOVES`（名前付きポーズ）と `ROUTINES`（セクション別の並び）を `tachie.ts` に持つ。
- **12fps・2コマ打ち**。切替は2コマ（少しオーバーシュート）→ 次の拍までピタッと止める。Aメロは2拍ごと、サビは1拍ごと＋小節末に決め。
- 腕も踊らせる（ギターのキャラは歌う所だけ右手がストローク）。
- 同じキャラを複数並べるときは **反転しない**（服のロゴが逆になる）。代わりに半拍ずらして別の動きにする（口パクはずらさない）。
- **最後のボーカルが消える所（`stopAt`）で全部止める**。決めポーズで静止し、曲の最後まで保持。
- 例: 3人カット（clones）は黒キャラ中央・カフェの子を左右、など。顔・体がかぶらない配置を静止画で確認する。

## 4. 歌詞レイアウト
- 1行ごとに見せ方を変える: 縦書きのギザギザ吹き出し / キャラの後ろに巨大文字（半透明）/ 下の帯 / ポップ（強調語だけ大きく）/ 斜めの半透明文字 / 中央の縦書き。
- **同じ行をカットをまたいで2回出さない**（カットが変わっても見せ方は行で決める）。
- 縦書きは **言葉の切れ目（空白・、・「・」の後）でだけ改行**。列の頭をそろえる。入らなければ文字を小さくする（例: 「ミスター・」「ヘンドレ！」）。
- キーワード（名前など）だけアクセント色（背景に映える色。例: 黄色の集中線にはシーンの赤）。縁取りは他の文字とそろえる。
- 吹き出し・Hey!/Ho! のバブルは **実際に測った文字サイズ** に合わせる。キャラの腕や顔に触れる位置は避ける（3人カットでは上の角だけ）。

## 5. ゲスト（小さいキャラ）の出し方
- 切り抜き → **絵柄をそろえる**（ベタ塗り寄り・線画・白いステッカー縁・影、薄く見えるなら明るさ/コントラスト/彩度を少し上げる）。縁の分だけサイズを補正する。
- **ずっと浮かせない**（ダンスの邪魔になる）。代わりに:
  1. ゲスト紹介: 間奏やイントロで1体ずつ拍に合わせてポップ＋「GUEST 名前」テロップ。
  2. 拍のぞき（peek）: 掛け声やアクセントの拍で、画面のふちから少し顔を出して引っ込む。方向をリズムで変える（左右交互・両側同時・上から逆さ吊り・下から・四隅から斜め）。12fps の2コマで出入り。**引き（duo / invert / letterbox）のカットだけ**で、見える量を制限（横 8.5%W・上下 20%H・角 11%W）。歌詞とキャラにかぶらない時刻・位置を選ぶ。
  3. ラストの集合写真: 最後の停止に合わせてキャラの足元に集まり、そのまま静止。
- 設定は `tachie.json` の `guests`（`items`・`peeks`・`group`）と間奏ステージの `pause`（`telop`・`intro`）。

## 6. 2周構成（1周目 → 間奏テロップ → 2周目）
- 2周目の開始は **拍の整数倍** にずらす（拍の位置がずれない）。各ステージに `win: [開始, 終了]` を書き、その周の歌詞だけ使う。声の音量データも同じだけずらす。
- 間奏は `guest_intro.tachie.json`（`pause`）で「次はゲストと一緒に」＋ゲスト紹介。
- 音源のつなぎ目: 1周目の終わりに **0.3秒フェードアウト**、2周目の頭に 20–50ms のフェードイン。無音部分がきれいか（DCずれ・クリックなし）を波形で確認。

## 7. エディターと一緒に使うための決まり（重要・標準の作り）
- **標準の作り＝「ステージの見た目が既定値＋エディターの行ごと・シーンごとの変更が必ず優先」**（パック共通ルール。AGENTS.md「エディターで後から直せること」）。
  - 変更したかどうかは `original-source.json` との差分で判定（`src/lib/lyricEdits.tsx` の `markEdited`）。エディター画面と `server.py`（保存・書き出し）が各行に `edited: [...]` を付ける。エディターの初期値は変更扱いにしない。
  - 未編集の行は、ステージ本来の見た目（行ごとの縦書き吹き出し／後ろに大きく／帯／ポップ／斜め／中央縦書き）のまま。描画は v6.4 と同じ（テストで比較）。
  - 書体・文字色・縁の色・強調色・文字倍率・高さ・配置（9か所）・角度・効果（影・光彩など）・入り方/消え方・開始/終了秒 → その行のステージスタイルにそのまま効く（`Tachie.tsx` の `wrap`）。
  - モーションの見本を選んだ行（一括適用を含む）→ その行だけエディター通常のモーション描画で出す（ステージは描かない）。
  - エディターの「ステージの文字スタイル（立ち絵など）」で、行ごとに縦書き吹き出し・後ろに大きく・下の帯・ポップ・斜めの半透明・中央の縦書きを選べる（`stageStyle`、「おまかせ」で元に戻る）。
  - シーンのカメラ・拡大・位置を変えたら、ステージのカットに加えて適用される。
  - **キャラ・ゲスト・テロップもエディターで直せる**（v6.6）：「シーン」タブの下の方。
    - キャラの位置・大きさ（このカット）：横/縦にずらす・大きさ・左右反転・隠す（どのレイアウトでも効く）。「このカットの設定を全シーンへ」「元に戻す」。
    - ゲスト（全体）：ゲストを出す／のぞき込み／アップ・分割でも出す／集合写真、ゲストごとの名前・出す・大きさ。
    - のぞき込み一覧：出す・ゲスト・秒・拍数・方向（左右・上・下・四隅）・位置・大きさ、追加・削除。集合写真：横位置・足元の高さ・大きさ。
    - 名前タグ（GUEST）：文字・色・大きさ・出す。登場テロップ・名前テロップの追加（文字・秒・位置）。
    - 間奏テロップ：文字・開始/消える秒・縦位置・大きさ・文字色・縁の色・帯（出す・色・線の色）。ゲスト紹介：登場秒・位置・大きさ・出す。
    - 保存は `data.stage`（全体）と `scenes[].stage`（カット）のパッチ。ステージ定義は変わらない。
  - 編集した行は歌詞一覧に ✎ が付き、「選択中の歌詞」に「編集済み: …」と出る。
  - 行が変わっても「同じ歌詞を2回出さない」「縦書きは言葉の切れ目で改行」はそのまま守られる。
  - 新しいステージを作ったら `tests/editor_overrides.test.tsx` の `FIXTURES` に追加する。
- 起動時にステージ定義を読み直したら、`editor-state.json` と **`original-source.json` の assets も同じ内容にそろえる**（ずれると書き出しが「元素材の指定は保持してください」で止まる。`scripts/editor.ts` で対応済み）。
- MP4 書き出し（`editor/export.mjs`）には、リグのパーツだけでなく **ゲスト・浮遊素材の画像も全部含める**（対応済み）。
- エディター画面は **プレビューだけ上に固定、タイムラインはスクロールで流れる**（「タイムラインも固定」は既定 OFF）。下のパネル（モーションの見本・画の切替など）が見えなくならないように。
- 配布zipでエディター関係のファイルを一部だけ入れない（古いファイルと混ざって画面が崩れる）。入れるならエディター一式をそろえる。

## 8. 確認チェックリスト
- [ ] 元絵との重ね・腕の回転の拡大比較（肩が細くならない／袖の形が残る）
- [ ] 各カットの静止画（3人カット・アップ・分割）で顔・体・歌詞がかぶらない
- [ ] 同じ歌詞が2回出ていない／縦書きが言葉の途中で切れていない
- [ ] 最後のボーカルで全員止まる／ゲストの集合が歌詞を隠さない
- [ ] つなぎ目の音（波形）
- [ ] エディターで開ける・保存できる・MP4 が書き出せる（短い書き出しで確認してから本番）
- [ ] エディターでキャラの位置・ゲスト・間奏テロップを1つずつ変える → その部分だけ変わる（1周目は変わらない）／「元に戻す」で元通り
- [ ] エディターで1行の書体・色・配置と見本モーションを変える → その行だけ変わり、他の行は元の見た目のまま／保存・書き出しにも反映（`npm test` の `editor_overrides` が通る）

## パック内での実行

このファイルは配布用コピー。編集原本は管理用ワークスペースの `.agents/skills/`。制作時は、この配布パックのルートにある `AGENTS.md` を読み、コマンドは `remotion/` で実行する。本文の `input/`、`projects/`、`docs/`、`gen/` はパックのルートを基準に解決する。
