# mv-import-clips

**モデルの目安: 軽い/速いモデル＋推論 low〜medium で十分**（決まった手順をコマンドで回す工程。`codex --profile mv-run`）

## やること
1. 動画を `input/` に入れる（mp4/mov/webm）。
2. `npm run scenes` でシーン切り替わりを検出（ffmpeg の scene スコア）。結果は `media.json` にキャッシュ。
3. `npm run mv` で、各カットに「動きが大きい場面（ベストモーメント）」の中央が来るように自動トリミング。画像と動画の混在もOK。
4. 元の全長動画は不変で保持し、使用開始位置・尺・速度を編集データに記録する。確認用のカット済みMP4を唯一の編集素材にしない。速度調整は曲・演技・ユーザーの意図に合わせ、歌唱シーンへ自動的にスローを適用しない。設定の対応範囲は実コードで確認する（通常のShotにはrate/rampがあるが、設定経路からの反映も検証する）。

## 注意
動画の音声は原則ミュートで取り込み、曲を独立トラックにする。生成音声と元曲の二重再生を防止する。

Studio移行時は [編集素材と履歴](../mv-workflow/references/review-and-studio.md) に従い、採用テイク、生成元、素材側のトリム、タイムライン位置、クロップ/効果、速度を区別する。焼き込み済みの修正を自由に元へ戻せるとは説明しない。

## パック内での実行

このファイルは配布用コピー。編集原本は管理用ワークスペースの `.agents/skills/`。制作時は、この配布パックのルートにある `AGENTS.md` を読み、コマンドは `remotion/` で実行する。本文の `input/`、`projects/`、`docs/`、`gen/` はパックのルートを基準に解決する。
