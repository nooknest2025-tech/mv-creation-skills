# mv-beat-edit

**モデルの目安: 標準モデル＋推論 medium**（迷ったら mv-direct で方針→ mv-run で実行）

## 仕組み
- カット長はプリセット×セクションで決まる（1小節 / 2拍 / 1拍 / 半拍 / 1/4拍、0 = 長回し）。サビは回を追うごとに細かく（エスカレーション）、エネルギーが高い所はさらに半分、静かな所は息継ぎで長く。
- カットは拍にスナップし、さらに `cutLead`（既定は約1〜3フレーム前）で前倒し → 人の目には「音ぴったり」に見える。
- プレサビの最後に半拍の黒ブレイク、冒頭はヒーローショット、終わりは最初の画に戻るループ（プリセットによる）。

## 調整
`npm run edit -- "サビは1/4拍で刻んで"` / `"Aメロは2小節ずつ"` / `"長回しで"` / `"画は0.1秒前から切り替え"` / `"BPMは128"` / `"拍を半拍ずらして"`
セクション別: `timing.perSection.chorus.cutLead`、ショット別: `timing.perShot`。視覚的には `npm run timing`。
