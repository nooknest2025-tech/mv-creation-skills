# mv-concept-storyboard

**モデルの目安: 強いモデル＋推論 high**（判断が多い工程。`codex --profile mv-direct`）

## やること
1. 新規制作は [mv-workflow](../mv-workflow/SKILL.md) の最初の選択を引き継ぐ。曲の印象・歌詞のテーマ・素材を確認し、ユーザーが選んだ作り方に沿う。素材だけから「おまかせ」と解釈しない。
2. プリセットを選ぶ（自動選択の理由は mv 実行時に表示される）:
   ストーリー / ダンス / リップシンク / ライブ / ボカロ / ファーストテイク風。変更は `npm run edit -- "ボカロっぽく"`。
3. `docs/hit_direction_playbook_ja.md` の型から、この曲に合うものを2〜3個だけ提案する（例: 冒頭3秒のフック、プレサビのブレイク、サビで段階的に派手に、ループする終わり方）。プリセットの recipes に既に入っているので、ON/OFF と強さの相談でよい。
4. 秒数区間・歌詞・素材・動き・文字演出の構成表を提示する。利用可能なMCPを確認し、静止画・パーツアニメーション・生成動画の使い方と選定理由を含める。
5. `npm run preview` の静止画などで画面を具体化して合意する。動きが重要な箇所は短い動きの見本も用意する。静止画の合意を歌詞同期や動画全体の確認済みとして扱わない。

## 歌唱中心の演出

声の強さと感情を分けて設計する。力強い曲の中でも、拒絶・誘い・確信・切実さなどを目線、顎、口元、姿勢、手の動きで変える。「繊細な感情」を勝手に弱い発声へ置き換えない。冒頭がセリフか歌唱かは音源と歌詞で確かめる。

一人のスタジオ歌唱では、本人・衣装・ヘッドホン・マイク/ポップガードの形と配置を固定する。カメラ目線を避ける等の希望は各ショットへ引き継ぐ。角度の違い、寄り、正面、手の表現は曲に合わせて組み、生成シーン間の不連続を編集で隠す選択肢も検討する。特定の曲での演技や画角を全MVの必須条件にしない。

## 決めること（mv.config.json に入る）
`preset`, `aspect`/`aspects`, `subject`（生成プロンプトで使う主役の説明）, セクション別の文字スタイル, 見せ場のセクション。

## パック内での実行

このファイルは配布用コピー。編集原本は管理用ワークスペースの `.agents/skills/`。制作時は、この配布パックのルートにある `AGENTS.md` を読み、コマンドは `remotion/` で実行する。本文の `input/`、`projects/`、`docs/`、`gen/` はパックのルートを基準に解決する。
