# 共通エディタの局所編集（v2.7以降）

歌詞の時刻・分割・一括適用、映像の部分速度・境界・結合、上段の編集、既存画面の更新で読む。曲固有の例やPC固有のポートを既定値にしない。

## 既存の編集を引き継ぐ

`remotion/` で `npm run editor -- --project <名前>` を実行し、表示されたURLを使う。保存先は `projects/<名前>/out/editor/editor-state.json`。新規制作や再解析をやり直して手編集を置き換えない。画面を開く依頼では、対象プロジェクトが開いたことまで確認する。

本体更新後の既存画面には `npm run editor:update -- --project <名前>`（全曲なら `--all`）で画面ファイルを反映する。先に未保存の変更を保存する。これはサーバー再起動のコマンドではない。保存検査を含む更新では、そのプロジェクトの旧サーバーを通常の方法で終了して `npm run editor -- --project <名前>` で再起動し、表示URLで再読込する。別プロジェクトのプロセスを止めない。保存失敗中の再読込で調整を失わせない。

## JIZURAの時刻・分割・適用

- タイムラインの端・開始終了の数値・詳細表で行を伸縮すると、手動表示パートと効果開始時刻も新しい行尺に比例して伸縮する。行全体の移動は内部の相対時刻を保つ。時刻変更のたびに手動パートを消す必要はない。JSONを直接直す場合は同じ変換を行い、パート時刻を行内へ収める。
- 歌詞の分割・結合は元歌詞への対応とパートの文字を保持する。対応不明な文字や1行24パートの上限超過は理由付きで止まる。重なる行を結合すると新しい行の中でパートを順に配置するため、歌唱との同期を再確認する。
- 通常モーションの見本・一括適用・詳細表から変更すると、その行の描画方式も通常へ切り替わる。手動のJIZURAパートは戻すために保持する。JIZURAを使い続けたい場合は、その字組み・出入りを変更する。
- 「組み合わせ・見た目すべて」は文字の不透明度、JIZURAの文字効果、画面効果も含む。効果開始時刻は対象行の長さに合わせ、本文・元歌詞への対応・行の開始終了・対象行の手動パートは保持する。適用先と項目を確認し、モーションだけの適用と区別する。
- 行全体の字組み・登場・保持・退場を明示変更すると手動パートにも反映する。その後パート単位で指定できる。「中央」「タイプ」の改行しない設定は、それに対応する字組みのパートで使う。

## 一部だけ動画の速度を変える

1. 対象の始まりと終わりへ再生位置を合わせ、各位置で「ここで切る（S）」を使う。
2. 中間のシーンを選び、動画の速さを変更する。タイムライン上の長さ・曲・隣の速度は変わらない。消費する素材の範囲が変わる。
3. 同じ素材が続く場合の「次のカットの使い始めを追従させる」を目的に合わせる。ONは中間区間の終わりから次の素材INをつなぐ。OFFは次の素材INを固定するため、境目で素材の時間が飛んだり重複したりする場合がある。「前のカットの終わりに続ける」は選択区間のINを前に従わせる。タイムラインの赤線を追いかける「追従 ON/OFF」とは別の機能。

分割だけでは元の滑らかな速度曲線・カメラ進行・乱数を保つ。カメラを区間頭から始めたい場合は「動きをこのシーンの頭から始める」を使う。分割後に速度を明示変更すると、保持していた曲線からその区間の速度設定へ切り替わる。指定速度で素材が足りない場合は末尾を保持する。尺優先の自動調整を改めて選ぶと実速度が変わり得るので、速度表示と境界を再生確認する。フェード中など対応できない位置の分割は理由付きで止まる。

## 境界と結合

数値の開始・終了と端ドラッグは、同じ「映像ごとトリム（速度を保つ）」が既定。素材INも動かして境界を切る・伸ばす。「切替時刻だけ（尺を合わせ直す）」は別の意味の編集で、端ドラッグではAltでも指定できる。終了秒の変更は次のシーンの開始も動かす。先に操作モードを確認する。

結合は、素材の連続性・カメラ・効果・速度曲線を保持できる場合に使う。異なる素材や離れた使用区間など、後半の映像を失う結合は拒否される。拒否を回避するため後半を削除せず、別シーンとして残す。境界の直前・途中・直後を確認する。

## 上段に重ねた画像・動画

「＋上段に重ねる」で追加し、「重ねる映像を選択」で対象を選ぶ。上段は下段とは別の表示区間で、切替をまたげる。「画面上で上段を移動」をONにするとプレビュー上で動かせる。「縦横比を保つ」は現在の幅と高さの比率を保つ。素材差替えでは素材の開始秒が0に戻るため、必要なら使い始めを設定する。

位置は各軸−100〜100%、幅・高さは5〜200%。画面からはみ出た部分は出力枠で切れる。動画の速さは0.1〜4倍。左端のトリムは速度に応じて素材INも動く。素材長が分かる動画が足りなくなれば最後の画を保持する。上段素材の音は再生せず元の曲を使う。歌詞なしのプロジェクトも開いて保存できる。

## 確認する範囲

変更した対象のプレビュー・保存・再読込・書き出しへの反映を確認する。エディタ自体の修正や移行の検証は検証用コピーで行い、採用版へ試験的な変更を混ぜない。再起動後の保持と短い修正版出力も調べる。関係のない全編を書き直す必要はない。音声の不変、技術的な連動、歌唱との同期、美的な採用を区別して記録する。
