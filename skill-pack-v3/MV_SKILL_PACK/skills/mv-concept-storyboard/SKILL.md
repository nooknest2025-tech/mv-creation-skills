# mv-concept-storyboard

**モデルの目安: 強いモデル＋推論 high**（判断が多い工程。`codex --profile mv-direct`）

## やること
1. 新規制作は [mv-workflow](../mv-workflow/SKILL.md) の最初の選択を引き継ぐ。曲の印象・歌詞のテーマ・素材を確認し、ユーザーが選んだ作り方に沿う。素材だけから「おまかせ」と解釈しない。
2. [曲から演出を発想し、試して選ぶ](../mv-workflow/references/creative-direction.md) に沿って曲固有の核を決める。発想の違う候補を内部で比較し、推奨案を選ぶ。「センスよく」を簡素化や装飾の追加だけに置き換えない。
3. 同一区間の短い試作で、曲との関係、展開、意外性と納得、主役、記憶に残る画を比較・推敲する。おまかせではAIが選定を担い、ユーザーへの質問を増やさない。費用と既存の承認範囲を守る。
4. 採用した表現を実現するためにプリセットと素材制作の方法を選ぶ。ストーリー / ダンス / リップシンク / ライブ / ボカロ / ファーストテイク風は出発点にできるが、演出案そのものの代わりにしない。`docs/hit_direction_playbook_ja.md` の型は必要なものを選び、曲の狙いに合わない recipes は切る。
5. 秒数区間・歌詞・素材・動き・文字演出の構成表を提示する。各見せ場の音・言葉の根拠と前後の変化、利用可能な実装手段を含める。代表画面と音付き試作で方向性を具体化する。静止画の合意を歌詞同期や動画全体の確認済みとして扱わない。

## 組合せと画面設計

[演出の調査と判断](../mv-workflow/references/direction-research.md) の比較表を使い、動画・静止画・キャラ・文字の役割をセクションごとに決める。画・歌・文字のどれが主役か、次の場面へのつながり、既存エディターで変更できる範囲を示す。参照作品の固有の表現を再現する指示ではなく、構成上の判断として応用する。

## 歌唱中心の演出

声の強さと感情を分けて設計する。力強い曲の中でも、拒絶・誘い・確信・切実さなどを目線、顎、口元、姿勢、手の動きで変える。「繊細な感情」を勝手に弱い発声へ置き換えない。冒頭がセリフか歌唱かは音源と歌詞で確かめる。

一人のスタジオ歌唱では、本人・衣装・ヘッドホン・マイク/ポップガードの形と配置を固定する。カメラ目線を避ける等の希望は各ショットへ引き継ぐ。角度の違い、寄り、正面、手の表現は曲に合わせて組み、生成シーン間の不連続を編集で隠す選択肢も検討する。特定の曲での演技や画角を全MVの必須条件にしない。

## 決めること（mv.config.json に入る）
`preset`, `aspect`/`aspects`, `subject`（生成プロンプトで使う主役の説明）, セクション別の文字スタイル, 見せ場のセクション。

## パック内での実行

このファイルは配布用コピー。編集原本は管理用ワークスペースの `.agents/skills/`。制作時は、この配布パックのルートにある `AGENTS.md` を読み、コマンドは `remotion/` で実行する。本文の `input/`、`projects/`、`docs/`、`gen/` はパックのルートを基準に解決する。
