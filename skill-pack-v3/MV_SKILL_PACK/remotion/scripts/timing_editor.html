① 全体（ぜんぶにまとめて効く）

拍の位置合わせ（キックと動きがずれるとき）白い縦線（拍）を曲のドンに合わせます。マイナス＝早く／プラス＝遅く（秒）
画の切替を早める・遅らせる全部のカット（ピンクの線）をまとめて動かします。マイナス＝早く切り替わる（秒）
歌詞を早める・遅らせる全部の歌詞（青い帯）をまとめて動かします。マイナス＝早く出る（秒）
BPM（曲の速さ）拍の線の間隔。自動で測った値が違うときだけ直します

② 個別（えらんだものだけ）

下のタイムラインでカット（画像）か歌詞の帯をクリックすると、ここで個別に調整できます。
個別の値は①全体の値に足されます（全体＋個別）。
効く範囲：
秒
ドラッグでも動かせます。キーボードの ← → でも0.02秒ずつ。

プレビュー（再生位置の画と歌詞）

上から：波形と拍（太線＝小節の頭）／セクション（黄色の線はドラッグで移動）／カット（画像の切替。ピンク線＝切替の瞬間）／歌詞。何もない所をクリックでそこから再生。保存すると mv.config.json の timing に記録され、次の npm run mv に反映されます。
※この画面は「本番の自動作成（npm run mv）」用です。編集画面（歌詞と映像の編集）でのドラッグ・動画の速さは編集画面のMP4にだけ効きます。2つを同時に使わず、どちらか一方で仕上げてください。
